贪吃蛇大作战 - C++语言控制台游戏

项目简介
这是一款基于 Windows 控制台的经典贪吃蛇游戏，使用 C ++语言开发。在传统玩法基础上，增加了用户系统、多种游戏模式、道具系统、连击机制、成就与排行榜等丰富功能。

主要功能
- **用户注册与登录**：数据持久化存储，自动保存最高分、成就。
- **游戏模式**
  - 标准模式：经典贪吃蛇玩法。
  - 障碍模式：地图中随机生成障碍物，增加挑战。
- **难度选择**：简单 / 普通 / 困难，影响蛇的速度和基础分数。
- **道具系统**：随机出现5种道具（加速、减速、无敌、双倍分数、缩短蛇身），持续10秒。
- **连击机制**：3秒内连续吃到食物可累积连击，额外加分。
- **成就系统**：10项成就（初次游戏、得分100、连击大师等）。
- **排行榜**：显示历史最高分前十名。
- **游戏日志**：记录每局游戏的详细数据。
- **暂停/恢复**：空格键暂停，操作灵活。
